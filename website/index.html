Private local AI

Your browser. Your device.

Phil runs models locally with WebGPU. Prompts, page text, and chats stay on-device by default — no cloud inference, no Phil servers reading your work.

  • Chat, page context, goals, focus, and memories stay local.
  • Internet only when needed: first model download, optional Google web research, optional Gmail, optional Calendar.
  • Analytics and crash reporting default off.
